CoordCard

Coordinated-comment cluster detector for YouTube · MV3 Chrome extension · built by a 90-minute autonomous harness.

① The Project

What

A Chrome MV3 extension. One toolbar click scans the visible comment section of the current video, detects coordinated near-duplicate clusters, and red-cards each flagged cluster inline with concrete evidence. A single comment outside a detected cluster is never scored.

Why (cited facts)

  • Google TAG (Q1 2026) terminated 2,254 + 2,602 + 1,096 PRC-linked YouTube channels in one quarter; of that network 80% had 0 subscribers and comment loops ran among their own accounts.
  • Korea academic study (2024): 239 suspected coordinated accounts; one article drew 2,698 comments; one account posted 130 comments/day.

Algorithm v2 (cluster + signals + suppressor + score)

Normalize (NFKC, lowercase, strip URLs/emoji/punctuation) → character 4-gram Jaccard; a pair is near-dup at sim ≥ 0.70; union-find builds clusters (short <5-token comments skipped, singletons excluded).

Ttext-duplicate: min(1, size/5)
Bcoarse-time burst (same-bucket authors)
Rreply-ring from parentId tree
Aaccount-age (API mode only)

no-API: S = 0.50·T + 0.30·B + 0.20·R  |  API: S = 0.40·T + 0.25·B + 0.20·A + 0.15·R

4-part flag guard (all must hold)

S ≥ 0.70≥ 3 distinct authors≥ 2 positive signalssuppressor OFF

The deterministic organic-burst suppressor re-labels and never-flags fan chants (93-token lexicon), RIP/condolence storms, laughter floods, and ≥30%-emoji clusters.

Honesty (binding)

The only label is "Matches coordinated-posting patterns in this video." Clusters are scored, never individuals. A forbidden-terms list is enforced over src + the built bundle.

Non-goals

No IP tracking · no cross-video history · no auto-submitted reports · no accusatory labels · no scoring of isolated comments · no ML model · no third-party data egress · storage only in chrome.storage.local · never posts on the user's behalf.
